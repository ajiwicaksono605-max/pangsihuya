# Pangsihuya Website

Website landing page responsif untuk bisnis camilan Pangsihuya, terinspirasi oleh struktur website referensi Ngumbah Sepatu dan menu pada gambar yang diberikan.

## Isi
- `index.html` — halaman utama, menu, cerita brand, form pemesanan
- `style.css` — desain responsif desktop dan mobile
- `script.js` — kalkulasi total, pilihan menu, dan pemesanan via WhatsApp

## Cara menjalankan
Buka `index.html` di browser, atau deploy folder ini sebagai static site di Vercel.

## Sebelum dipublikasikan
Buka `script.js` dan ubah `WHATSAPP_NUMBER = "6281234567890"` ke nomor WhatsApp Pangsihuya yang benar (format internasional, tanpa tanda `+`).

Harga contoh yang dipakai:
- Pangsihuya Goreng: Rp10.000
- Pangsisa Goreng: Rp10.000
- Banana Bomb: Rp15.000

Silakan sesuaikan harga dan detail usaha bila berbeda.
